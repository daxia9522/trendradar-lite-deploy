# 原生 Linux 终端配置菜单：设计与验收

## 范围与边界

本次变更只针对原生 Linux 的配置体验，并复用已有配置能力。

- 入口命令为 `trendradar`；不将它用作新闻任务执行命令。
- 首次安装、后续配置共用分组菜单和配置读写、校验逻辑。
- Docker 原有向导、GitHub Actions 的 Secrets 工作流保持兼容。
- 不修改新闻采集、分析和邮件投递业务流程；配置保存不手动启动服务或执行这些测试，已有定时任务仍可按计划运行。
- 本地开发、测试不接触生产目录、真实用户配置、真实定时器，不推送远端。

## 交互

主菜单：邮件推送、AI 模型与接口、采集与推送时间、高级配置、查看待保存变更、保存并应用、放弃修改并退出。

1. 子菜单展示普通字段的当前值；秘密只展示设置状态。
2. 输入编号选择字段，不要求重填整个分组。
3. 回车保留；`:cancel` 取消字段编辑；可选字段用 `:clear` 清空。
4. 布尔项提供启用/停用选择；格式错误只要求重填当前字段。
5. 编辑只改变内存草稿。返回主菜单不会丢失草稿。
6. 变更预览显示旧值与新值；秘密仅显示新增、替换或清空。
7. 恢复原值后不再视为变更；放弃时确认，EOF/Ctrl-C 不落盘。
8. 保存前展示变更与应用影响，确认后执行；应用失败不能宣称成功。

高级配置仅包含已支持的不常用参数：`AI_TIMEOUT`、`PLATFORMS_API_URL`、`PLATFORMS_API_FALLBACK_URLS`，不引入任意命令入口。

## 单一配置逻辑

- 环境文件仍为 `${XDG_CONFIG_HOME:-$HOME/.config}/trendradar-lite/env`。
- 邮件、AI、调度、高级参数共用解析器与校验器。
- 保留菜单之外的变量和未经修改的内容，不能重建一个有限字段白名单导致数据丢失。
- 解析环境文件不执行 shell，妥善处理引号、反斜线、美元符号、反引号。
- 更新前建立私有备份；通过临时文件与原子替换写入，权限为 `0600`，保留已有文件 UID/GID（尤其是 Docker root setup）。环境备份目录 `.env.backups/` 已加入 Git 忽略规则。
- 检测菜单打开后发生的外部文件修改，拒绝覆盖而不是丢弃 `nano` 的修改。
- 验证必填字段、SMTP 配对、启用 AI 的凭据、布尔值、整数范围、时间格式、合法时区、正数超时、重复推送时间。

## 调度一致性

- 普通环境参数：下次 oneshot 启动读取，不重启任务，不刷新定时器。
- 时间变更：更新相关 systemd timer 与环境覆盖，显式处理时区，使任务触发时刻与程序推送窗口一致。
- 不直接改共享 `config/timeline.yaml` 来保存某台服务器的个性化时间；使用部署级覆盖。
- 保持定时器原来的启用/禁用及活动状态，不因维护而打开已关闭的任务；不执行 timer restart/start，也不清除触发时间戳。
- 仅 `daemon-reload` 也可能触发补跑：保存前、重载前以及需要回滚重载时，读取 timer 的稳定状态与 LastTriggerUSec，对旧/新日历进行只读校验。已错过、进入 120 秒安全窗口、或无法可靠核验时拒绝应用。
- 安全窗口是保守预检，不是对 systemd 的锁；外部时间跳变、挂起、管理员并发操作无法由配置工具绝对排除。新旧计划下一次触发必须均在安全窗口之外。
- 保留能够安全保留的 unit 指令；无法理解的自定义计划或 drop-in 拒绝自动覆盖并给出说明。
- 旧环境缺少时间字段时核对已有 timer、timeline 和时区配置。不得将模板默认值标成已生效值。
- 旧配置冲突或迁移需要用户明确确认，不得在只改 AI/邮件时顺便重置调度。
- 写入或应用失败时恢复能够恢复的文件，包括原子替换成功但 fsync 失败的场景；区分磁盘内容、持久化确认与运行时状态，不掩盖失败。

## 命令生命周期

- 安装器安装用户级入口 `~/.local/bin/trendradar`，定位安装所属的源码目录；任意工作目录可执行。
- 检查 PATH，提示绝对路径备用入口，不擅自编辑 shell 启动文件。
- 不覆盖其他程序占用的同名入口；卸载只删除本安装拥有的入口。
- `install.sh --configure` 为配置入口，不执行 pip 更新、代码更新或任务运行。
- 默认终端模式；网页仅显式选择。非交互会话给出说明，不自动监听端口。
- 首次安装取消后不得继续启用定时器。

## 隔离验证要求

- 菜单：单字段修改、错误重试、布尔值、清空、回退、变更预览、确认保存、确认放弃、EOF、Ctrl-C、脱敏。
- 文件：未知参数、评论、特殊字符、转义尾空白/EOF、私有备份、所有者保留、原子替换、并发修改保护；以 systemd 共享库离线解析器和 Compose config 对照。
- 调度：默认/自定义时区、四个日推时间、周报、保留关闭状态、补跑预检拒绝、120 秒安全窗口、仅必要时 reload、replace 后失败恢复、旧配置冲突。
- 安装器：临时 HOME/XDG/PATH 与假 systemctl/Python，验证入口路径、取消安装、重配置无 pip、卸载归属。
- 回归：全部 Python 单测、编译检查、逐个 shell 语法检查、Compose 配置校验（工具可用时）。
- 全程禁止真实抓取、AI 调用、邮件投递和生产 systemd 操作。
